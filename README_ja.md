# chematic-draw

**Pure Rust** で書かれたオープンソースの化学構造描画エディタ。  
実験的なオフラインファーストの化学構造描画環境です。ChemDraw・ChemDoodle・Ketcher・ChemSketch の代替を目指していますが、まだドロップイン置き換えではなく、科学的正確性と相互運用性を優先して開発しています。

## 化学エンジン

すべての化学処理は [`chematic`](https://crates.io/crates/chematic) クレートで処理します。  
C/C++ FFI ゼロの Pure Rust 製 RDKit 代替ライブラリです。この表は各サブクレートが「できること」の一覧であり、すべてが UI に接続済みとは限りません（例: QED と互変異性体列挙は `chematic-chem` にありますが、chematic-draw の UI にはまだ接続されていません — 上記の機能比較表を参照）。

| サブクレート | 用途 |
|------------|------|
| `chematic-smiles` | SMILES 解析・生成・正規化 |
| `chematic-mol` | MOL V2000 / SDF 読み書き |
| `chematic-depict` | 2D 座標生成 |
| `chematic-chem` | 分子量・logP・TPSA・QED・Lipinski・互変異性体 |
| `chematic-3d` | 3D 座標生成 |
| `chematic-rxn` | 反応 SMILES |
| `chematic-fp` | 指紋（Morgan, ECFP） |
| `chematic-smarts` | SMARTS 部分構造検索 |

## ネットワーク依存について（名前による構造インポート）

IUPAC 名の**生成**（インスペクタパネル）はローカルのオフラインアルゴリズムで、ネットワークも PubChem も使用しません。ネットワークを必要とする唯一の機能は「名前による構造インポート」（ファイルメニュー）で、化合物名から構造を取得するために [PubChem REST API](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest) に問い合わせます。

```
GET https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/{name}/property/IsomericSMILES/JSON
```

- **インターネット接続が必要なのはこの機能のみ**です。
- バックグラウンドスレッドで実行され、通信中も UI はブロックされません。
- オフライン時や該当する名前が見つからない場合はインスペクタにエラーを表示し、UI をブロックしません。
- API キー不要。PubChem は NCBI / NIH が提供する無料の公共サービスです。
- PubChem から返されるデータは同サービスの[利用規約](https://www.ncbi.nlm.nih.gov/home/about/policies/)に従います。

描画・エクスポート・3D ビュアー・SMILES/MOL 貼り付け・IUPAC 名生成など、**他の全機能はオフラインで動作**します。
